# SynqLab docs

> **SynqLab is an AI lab for biology**: the agentic platform where a team and AI agents design, test and track new proteins and molecules. Aria is our protein agent: a self-improving AI, customized on a team's own data.
> Lyra, the small-molecule agent, is in development.

Start with [`strategy.md`](strategy.md). Current state is in [`STATUS.md`](STATUS.md).

├── platform.md          the SynqLab platform: architecture, tools layer, website diagram
├── design-spec.md       layers, loop, pack contract, experiment gates
├── market-research.md   competitors, size, costs, comparables
├── STATUS.md            what is happening now
├── demo-scenarios.md    demo scenarios: SynqLab agent chips (kept and removed), the GFP11 demo flow, Aria chat prompts

`archive/` is kept for reference only. It describes the pre-pivot story and its links are stale.
