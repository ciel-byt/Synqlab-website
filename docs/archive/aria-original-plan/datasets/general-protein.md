> **Provenance note (what is actually training data).** For V1, **Swiss-Prot is the only training corpus.** Its sequences are the generation targets; its own annotation columns (Pfam, EC, GO, organism, subcellular location) supply the *functional* prompt features directly — there is no separate Pfam/InterPro join in the pipeline. **AlphaFold DB** contributes exactly one feature (mean pLDDT) via accession join and is otherwise not training data. **Physicochemical** features (length, net charge @7.4, GRAVY, instability) are computed from each sequence with Biopython. **ProteinGym**, PDB, and TrEMBL are not used in V1 training (eval / future scale-up only).

## Terminology cheat sheet


| Term         | What it is                                                                                                                             | Example                                                                                           |
| ------------ | -------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| **TSV**      | A plain-text table, columns separated by tabs. Just a file format.                                                                     | `sequence\tlength\torganism`                                                                      |
| **mmCIF**    | File format for storing 3D protein structures (atomic coordinates). Modern version of `.pdb`.                                          | `.cif` file with x/y/z per atom                                                                   |
| **Pfam**     | Every protein is built from reusable pieces called *domains* — like ingredients in a dish. Pfam is the catalogue of known ingredients. | Trypsin contains `PF00089` = serine protease domain = "this part cuts proteins"                   |
| **InterPro** | Same idea as Pfam but combines 10 catalogues into one bigger list. More complete, same concept.                                        | Trypsin → `IPR001254` = "serine proteases, trypsin family"                                        |
| **EC class** | Only for enzymes. A 4-digit code for the exact chemical reaction — like "bake / fry / steam" but for chemistry.                        | `EC 3.4.21.1` → 3 = cuts things · 4 = cuts proteins · 21 = serine type · 1 = trypsin specifically |
| **GO terms** | Three questions about a protein: (1) what does it **do**? (2) what **process** is it part of? (3) **where** in the cell does it live?  | Trypsin → "cuts proteins" / "digestion" / "outside the cell"                                      |
|              |                                                                                                                                        |                                                                                                   |
