## Milestone 1: Agentic AI Platform

### Table Stakes (Must Have)

- [x] **REQ-01** Agent Console UI — Frontend chat interface with tool call visualization, integrated into the Lab hub
- [x] **REQ-02** Autonomy Modes — Copilot (approve each step), Supervised (checkpoints), Autonomous (end-to-end)
- [x] **REQ-03** Coordinator Agent — "Research Director" that spawns specialist workers for multi-step workflows
- [x] **REQ-04** Sub-Agent Lifecycle — Spawn, monitor, send messages to, and kill worker agents (Task pattern from Claude Code)
- [x] **REQ-05** Skill System — Markdown-based skills with YAML frontmatter, loaded from directories (core + user-uploaded)
- [x] **REQ-06** Streaming Events — Real-time WebSocket streaming of agent text, tool calls, and sub-agent status
- [x] **REQ-07** Multi-User Sessions — Concurrent agent sessions across users with proper isolation

### Differentiators (Should Have)

- [x] **REQ-08** Research Director Workflow — Autonomous pipeline: generate sequences → fold → analyze stability → report
- [x] **REQ-09** Pipeline Builder — Visual drag-and-drop pipeline editor (competitive parity with Tamarind Bio)
- [x] **REQ-10** Agent Artifacts — PDB file output, markdown reports, comparison tables persisted to project storage
- [x] **REQ-11** Token/Cost Controls — Per-session and per-org token limits, usage dashboards
- [x] **REQ-12** Batch Processing — Submit multiple sequences/structures for parallel agent processing

### Nice to Have

- [x] **REQ-13** Agent Templates — Pre-configured agent profiles for common workflows (protein optimization, binder design)
- **REQ-14** Skill Marketplace — Share and discover community-created skills *(deferred to Milestone 2)*
- **REQ-15** Agent Memory — Cross-session learning (context carryover between conversations) *(deferred to Milestone 2)*
