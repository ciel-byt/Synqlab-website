## Milestone 1: Agentic AI Platform

### Phase 1: Agent Console Frontend ✦ `agent-console-ui`
**Goal:** Ship the frontend Agent Console UI so researchers can interact with the single-agent engine built in the backend.
**Requirements:** REQ-01, REQ-06
**Depends on:** Backend agent system (completed)

- Agent chat interface with markdown rendering
- Tool call visualization (expandable cards showing inputs/outputs)
- Session management (create, list, resume, delete)
- WebSocket integration for real-time streaming
- Integration into existing Lab hub sidebar

---

### Phase 2: Autonomy Modes ✦ `autonomy-modes`
**Goal:** Implement three autonomy levels so researchers can choose their comfort level.
**Requirements:** REQ-02
**Depends on:** Phase 1

- Copilot mode: agent proposes tool calls, user approves each one
- Supervised mode: agent runs full workflow, pauses at configurable checkpoints
- Autonomous mode: agent runs end-to-end, user gets final report
- Mode selector in Agent Console UI
- Per-session mode persistence

---

### Phase 3: Coordinator & Sub-Agents ✦ `coordinator-subagents`
**Goal:** Implement the coordinator/worker pattern from Claude Code so a "Research Director" agent can spawn specialist workers.
**Requirements:** REQ-03, REQ-04, REQ-07
**Depends on:** Phase 2

- `CoordinatorEngine` — restricted to spawn/message/stop tools only
- `WorkerEngine` — full tool access, reports results back to coordinator
- Task lifecycle: pending → running → completed/failed/killed
- Agent-to-agent messaging (SendMessage pattern)
- Sub-agent status tracking in DB (`agent_tasks` table)
- Concurrent session isolation (multi-user)
- Coordinator UI: sub-agent tree view with live status

---

### Phase 4: Skill System ✦ `skill-system`
**Goal:** Implement extensible skill system so researchers can create and share custom workflows.
**Requirements:** REQ-05
**Depends on:** Phase 3

- Skill definition format: SKILL.md with YAML frontmatter (name, description, tools, autonomy)
- Skill loader: scan directories for skill definitions
- Core skills: bundled scientific workflows (protein optimization, binder design)
- User skills: upload/create custom skills per org/project
- Skill discovery: agent can browse available skills
- Skill execution: agent loads skill markdown as system prompt extension

---

### Phase 5: Research Director Workflow ✦ `research-director`
**Goal:** Ship the flagship autonomous workflow: generate → fold → analyze → report.
**Requirements:** REQ-08, REQ-10
**Depends on:** Phase 3, Phase 4

- Research Director agent profile with multi-step protocol
- Automatic sequence generation → structure prediction pipeline
- Stability analysis with ranked results
- Markdown report generation with embedded metrics
- Artifact persistence (PDB files, score tables)
- End-to-end demo: "Design a stable binder for target X"

---

### Phase 6: Pipeline Builder & Batch Processing ✦ `pipeline-batch`
**Goal:** Visual pipeline editor and batch processing for competitive parity with Tamarind Bio.
**Requirements:** REQ-09, REQ-12
**Depends on:** Phase 5

- Pipeline definition format (DAG of tool nodes)
- Visual pipeline editor (drag-and-drop in frontend)
- Batch input: CSV/FASTA upload for parallel processing
- Pipeline execution engine (maps to agent tool calls)
- Progress tracking and result aggregation

---

### Phase 7: Cost Controls & Agent Templates ✦ `cost-templates`
**Goal:** Token usage limits and pre-configured agent profiles.
**Requirements:** REQ-11, REQ-13
**Depends on:** Phase 5

- Per-session token budget with soft/hard limits
- Per-org monthly token quotas
- Usage dashboard (tokens, costs, tool calls per session)
- Agent template system: pre-configured profiles
- Template library: protein optimization, binder design, literature review
