# Plan 27-04: Tab & Route Restructuring

## Objective

Move the Skills route from `/lab/skills` into the Agents route group at `/lab/agents/skills`, and rename the "Datasets" nav label to "Storage". Add a backward-compatible redirect for the old `/lab/skills` path.

## must_haves

- [ ] `/lab/agents/skills` serves the SkillsPage component
- [ ] `/lab/skills` redirects to `/lab/agents/skills` (backward compat)
- [ ] Agent console "View all skills" link updated to `/lab/agents/skills`
- [ ] Sidebar nav label reads "Storage" instead of "Datasets" for the datasets route

## Tasks

<task id="1">
<title>Move Skills route into Agents block in App.tsx</title>

<read_first>
- frontend/src/App.tsx (lines 87-109 — lab/agents route block)
</read_first>

<action>
Modify `frontend/src/App.tsx`:

1. **Add Skills route inside the agents block** (after line 102, before the closing `</Route>` on line 103):
```tsx
              <Route path="skills" element={<SkillsPage />} />
```

2. **Replace the existing standalone Skills route** (line 106):
Change from:
```tsx
            <Route path="skills" element={<SkillsPage />} />
```
To:
```tsx
            <Route path="skills" element={<Navigate to="/lab/agents/skills" replace />} />
```

The resulting agents block should look like:
```tsx
            <Route path="agents" element={<AgentsLayout />}>
              <Route index element={<Navigate to="/lab/agents/console" replace />} />
              <Route path="console" element={<AgentsConsoleLayout />}>
                <Route index element={<AgentConsoleView />} />
              </Route>
              <Route path="designer" element={<AgentsHub />} />
              <Route path="designer/:pipelineId" element={<AgentDesignerCanvasPage />} />
              <Route path="datasets" element={<AgentDatasetsPage />} />
              <Route path="skills" element={<SkillsPage />} />
            </Route>
```

And the old standalone route becomes:
```tsx
            <Route path="skills" element={<Navigate to="/lab/agents/skills" replace />} />
```
</action>

<acceptance_criteria>
- `grep -c 'path="skills"' frontend/src/App.tsx` returns 2 (one inside agents, one redirect)
- `grep '/lab/agents/skills' frontend/src/App.tsx` returns a match (the redirect target)
- `grep -c 'Navigate.*agents/skills' frontend/src/App.tsx` returns 1
</acceptance_criteria>
</task>
