# Plan 27-03: Storage Browser Page

## Objective

Replace the current `AgentDatasetsPage` with a namespace-aware file browser that uses the new `/api/storage/browse` and `/api/storage/download` endpoints. The browser shows a left-side namespace tree and a right-side file listing with breadcrumb navigation.

- [ ] `StorageBrowser` component renders namespace tree on left, file listing on right
- [ ] `api.browseStorage(path)` and `api.downloadStorageFile(path)` methods added to client.ts
- [ ] Breadcrumb navigation works at all depth levels
- [ ] File preview via Sheet slide-in panel (PDB, JSON, CSV, FASTA)
- [ ] Download button per file
- [ ] Empty state shown for empty namespaces

Add to `frontend/src/api/client.ts` in the API object:

```typescript
// Storage browser
browseStorage: (path: string = '') => {
  const params = new URLSearchParams()
  if (path) params.set('path', path)
  const qs = params.toString()
  return apiFetch<{
    entries: Array<{
      name: string
      is_dir: boolean
      size: number | null
      modified: string
      path: string
    }>
    namespace: string
    path: string
  }>(`/api/storage/browse${qs ? '?' + qs : ''}`)
},

downloadStorageFile: (path: string) => {
  // Returns a direct download URL (no fetch — browser handles download)
  const params = new URLSearchParams({ path })
  return `${API_BASE}/api/storage/download?${params.toString()}`
},
```

Note: `downloadStorageFile` returns a URL string, not a fetch call. The StorageBrowser will set `window.location.href` or use an `<a>` tag.

Also add the `StorageEntry` type export near the other type definitions:

```typescript
export interface StorageEntry {
  name: string
  is_dir: boolean
  size: number | null
  modified: string
  path: string
}
```

```typescript
function formatSize(bytes: number | null): string {
  if (bytes === null) return '—'
  if (bytes < 1024) return `${bytes} B`
  if (bytes < 1024 * 1024) return `${(bytes / 1024).toFixed(1)} KB`
  return `${(bytes / (1024 * 1024)).toFixed(1)} MB`
}
```
