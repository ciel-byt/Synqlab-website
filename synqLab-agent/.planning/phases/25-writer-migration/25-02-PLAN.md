# Plan 25-02: Migrate Folding & Validation Tools

## Objective

Update `protein_folding.py`, `validate_complex.py`, and `stability_analysis.py` to send engine-scoped `artifact_dir` values to their respective services, routing outputs to the new namespace directories.

## must_haves

- [ ] `protein_folding.py` sends `ARTIFACT_DIR/folding/omegafold` or `ARTIFACT_DIR/folding/esmfold` as `artifact_dir`
- [ ] `validate_complex.py` sends `ARTIFACT_DIR/candidates` as `artifact_dir`
- [ ] `stability_analysis.py` sends `ARTIFACT_DIR/foldx` as `artifact_dir` (replaces hardcoded `"/app/artifacts"`)
- [ ] All three tools import from `synqlab.storage.artifact_paths`

## Tasks

<task id="1">
<title>Migrate protein_folding.py to use FOLDING namespace</title>

<read_first>
- synqlab/agent/tools/protein_folding.py (lines 79-82 — current artifact_dir)
- synqlab/storage/artifact_paths.py (import targets)
- synqlab/agent/tools/_persist.py (line 26 — ARTIFACT_DIR constant)
</read_first>

<action>
1. Add imports at top of `protein_folding.py` (after existing imports, before `logger`):
```python
from synqlab.storage.artifact_paths import FOLDING, build_agent_artifact_path
from synqlab.agent.tools._persist import ARTIFACT_DIR
```

2. Replace lines 79-81:
```python
# OLD:
"artifact_dir": os.environ.get(
    "SYNQLAB_ARTIFACT_DIR", "/app/data/agent_artifacts"
),
# NEW:
"artifact_dir": str(build_agent_artifact_path(ARTIFACT_DIR, FOLDING, method)),
```

This sends `data/agent_artifacts/folding/omegafold` or `data/agent_artifacts/folding/esmfold` as the `artifact_dir`, so the service writes files under the engine-scoped directory.
</action>

<acceptance_criteria>
- `grep "build_agent_artifact_path" synqlab/agent/tools/protein_folding.py` returns 1 match

- `grep "FOLDING" synqlab/agent/tools/protein_folding.py` returns at least 1 match

</task>
