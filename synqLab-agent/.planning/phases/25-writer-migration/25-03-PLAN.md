# Plan 25-03: Migrate FoldX Adapter & Pipeline Router

## Objective

Update `foldx.py` adapter and `pipelines.py` router to use `build_agent_artifact_path` for their work-directory and run-store paths.

## must_haves

- [ ] `foldx.py` uses `build_agent_artifact_path(artifact_dir, FOLDX, run_id)` instead of `Path(artifact_dir) / f"foldx_{run_id}"`
- [ ] `pipelines.py` uses `build_agent_artifact_path(ARTIFACT_DIR, PIPELINES)` instead of hardcoded `"pipeline_runs"` string
- [ ] Docker Compose `volumes:` remains unchanged

## Tasks

<task id="1">
<title>Migrate foldx.py adapter work directory</title>

<read_first>
- synqlab/adapters/foldx.py (line 228 — current work_dir construction)
- synqlab/storage/artifact_paths.py (import targets)
</read_first>

<action>
1. Add import at top of `foldx.py` (after existing imports, before `logger`):
```python
from synqlab.storage.artifact_paths import FOLDX, build_agent_artifact_path
```

2. Replace line 228:
```python
# OLD:
work_dir = Path(artifact_dir) / f"foldx_{run_id}"

work_dir = build_agent_artifact_path(Path(artifact_dir), FOLDX, run_id)
```

Note: `artifact_dir` comes from `request.inputs` and may be a string. The `Path()` wrapping is preserved.
</action>

</acceptance_criteria>
</task>

<task id="2">
<title>Migrate pipelines.py run store directory</title>

<read_first>
- app/routers/pipelines.py (lines 41-44 — _RUNS_DIR construction)
- synqlab/storage/artifact_paths.py (import targets)
</read_first>

<action>
1. Add import near top of `pipelines.py` (replace the inline `pathlib` import):
```python
from synqlab.storage.artifact_paths import PIPELINES, build_agent_artifact_path
```

2. Replace lines 38-44:
```python
# OLD:
# File-backed storage for pipeline runs (persists across restarts).
import pathlib as _pathlib

_RUNS_DIR = _pathlib.Path(
    os.environ.get("SYNQLAB_ARTIFACT_DIR", "data/agent_artifacts")
) / "pipeline_runs"
_RUNS_DIR.mkdir(parents=True, exist_ok=True)

# NEW:
# File-backed storage for pipeline runs (persists across restarts).
from pathlib import Path as _Path

_RUNS_DIR = build_agent_artifact_path(
    _Path(os.environ.get("SYNQLAB_ARTIFACT_DIR", "data/agent_artifacts")),
    PIPELINES,
)
_RUNS_DIR.mkdir(parents=True, exist_ok=True)
```

This changes the output directory from `pipeline_runs/` to `pipelines/`. Existing runs in `pipeline_runs/` stay on disk (per discussion decision).
</action>

<acceptance_criteria>
- `grep "pipeline_runs" app/routers/pipelines.py` returns 0 matches (old constant removed)
- `grep "build_agent_artifact_path" app/routers/pipelines.py` returns 1 match
- `grep "PIPELINES" app/routers/pipelines.py` returns at least 1 match
- `python -c "from app.routers.pipelines import router; print('OK')"` prints OK
</acceptance_criteria>
</task>
