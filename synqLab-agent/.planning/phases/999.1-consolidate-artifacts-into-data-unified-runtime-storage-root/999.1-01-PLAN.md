# Plan 999.1-01: Consolidate artifacts/ into data/

## Objective

Merge the legacy `artifacts/` directory into `data/` to create a single runtime
storage root. Update all references across Python source, scripts, configs,
Docker infrastructure, Helm charts, and tests.

## Mapping Table

| Old Path | New Path | Subsystem |
|----------|----------|-----------|
| `artifacts/brightness/` | `data/models/brightness/` | brightness adapter, training script |
| `artifacts/reranker/` | `data/models/reranker/` | reranker adapter, service, training script |
| `artifacts/knowledge/` | `data/knowledge/` | knowledge store, ingest script |
| `artifacts/omegafold/` | `data/agent_artifacts/folding/omegafold/` | run_omegafold script |
| `artifacts/esmfold/` | `data/agent_artifacts/folding/esmfold/` | run_esmfold script |
| `artifacts/user_media/` | `data/user_media/` | Dockerfile, docker-compose |
